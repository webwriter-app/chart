Radar Chart

The Chart Widget offers three initial tabs which can be extended by adding more visualization options. The first tab lets users enter and modify their data. The second tab displays a scatter plot, and the third displays all other possible chart visualization options. The user can select between pie, doughnut, bar, line, polar area, and radar charts.

The following displays an example of a Radar Chart. Here, the user can select which data defines the x-axis and filter for selected datasets. By clicking on the legend, each respective data point can be hidden.
