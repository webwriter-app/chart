# Widget for Data Visualization and Exploration in Interactive Worksheets

This project aims to develop an interactive data visualization widget for the WebWriter tool, with the goal of improving data literacy and facilitating the learning of mathematical concepts in schools.

_This Project is part of my bachelors thesis at RWTH Aachen i9._

## Motivation

Data visualization is a critical skill for understanding complex information and making informed decisions. In addition, studies have shown that interactive diagrams can aid in the learning of mathematical concepts. The development of an interactive data visualization widget can help bridge the gap between traditional teaching methods and modern learning techniques.

## Objective

This thesis is focused on developing a intuitive widget for the WebWriter tool that provides both static and interactive data visualization options. The widget is intended to be used by teachers to create interactive worksheets for their students. To minimize the time required for teachers to use the tool, the widget will use the WYSIWYG (What-You-See-Is-What-You-Get) principle wherever possible.

## Features

The widget will include the following features:

- Static visualization of data
- Interactive diagrams for exploratory exploration
- Linked diagrams for dynamic exploration
- WYSIWYG principle for ease of use

## Getting Started

There are two ways to use the widget:

- Install the "ww-chart" npm package in your WebWriter tool
- Access the widget through the URL https://ba.luiskugel.de if you do not have the WebWriter tool installed

## Usage

After installing the "ww-chart" npm package, you can easily add the widget to your digital worksheet.
